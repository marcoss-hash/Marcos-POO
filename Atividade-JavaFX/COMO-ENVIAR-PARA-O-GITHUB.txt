1. Extraia a pasta Atividade-JavaFX dentro da pasta principal do seu repositório Marcos-POO.
2. Abra o terminal na pasta principal Marcos-POO.
3. Execute:

   git add Atividade-JavaFX
   git commit -m "Adiciona atividade JavaFX com MVC e JPA"
   git push origin main

4. Atualize a página do GitHub e confira se a pasta Atividade-JavaFX apareceu.

Para rodar o projeto, entre na pasta Atividade-JavaFX e execute:

   mvn clean test
   mvn clean javafx:run

Requisitos: JDK 21 e Maven 3.9+ instalados. Na primeira execução, o Maven precisa baixar as dependências.
